# 🌍 迷你世界全息查询引擎 · 幻邃智能

由 **幻邃智能 (HuanSui AI)** 打造的一站式迷你世界数据查询系统，深度整合多个官方及第三方接口，提供最全面、最及时的玩家信息。

## 🚀 指令大全

| 指令 | 用法 | 功能 |
|------|------|------|
| `/菜单` | 直接发送 | 显示所有命令 |
| `/查询` | `/查询 <迷你号>` | 全息档案（资料/地图/追踪/礼物/家族/IP） |
| `/资料` | `/资料 <迷你号>` | 基础资料（来自冷雨API） |
| `/资料2` | `/资料2 <迷你号>` | 详细资料（VIP/信誉分/藏品等） |
| `/地图` | `/地图 <迷你号>` | 地图列表（前5个） |
| `/追踪` | `/追踪 <迷你号>` | 在线状态与房间信息 |
| `/礼物` | `/礼物 <迷你号>` | 礼物背包详情 |
| `/IP` | `/IP <迷你号>` | 地理位置与IP |
| `/家族` | `/家族 <迷你号>` | 家族信息 |

## 📊 数据维度
- **基础信息**：昵称、迷你号、等级、性别、签名、注册时间、最后在线
- **社交**：好友、关注、粉丝、待处理申请
- **VIP**：VIP状态、到期时间
- **声誉**：信誉分、魅力值、人气
- **创作**：地图数量、下载量、点赞数、作品数
- **收藏**：皮肤、坐骑、武器、称号、头像框、勋章、帖子、方块总值
- **家族**：名称、等级、介绍、成员数、活跃值、家族地图
- **追踪**：当前房间、人数、IP、公开/私有
- **礼物**：全部礼物种类及数量
