# 🌍 迷你世界查询 · Chuan

这是由 **我** 也就是 **Chuan** 开发的 AstrBot 插件，让你在聊天框里就能随时查迷你世界的玩家资料和地图，数据都来自官方接口，靠谱！

## 🎮 咋用？

| 指令 | 咋写 | 说明 |
|------|------|------|
| `查询` | `查询 123456` | 看这个玩家的所有信息，昵称、等级、好友数、签名啥都有。 |
| `查询地图` | `查询地图 123456` | 看他发了哪些地图，下载量、点赞数一目了然。 |

还有一堆别名也能触发，比如 `cx`、`地图查询`，怎么顺口怎么来！

## 📊 能看到啥？
*   **好友咋样**：好友数、关注数、粉丝数、有没有人申请加好友。
*   **做了啥图**：地图总数、总共被下载了多少次、获赞多少、访问量多少。
*   **地图长啥样**：地图名字、哪一季的（有的话）、啥时候建的、文件大小。
